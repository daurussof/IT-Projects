# IT Project Manager

Мобильное приложение для управления IT-проектами (Jira-подобная система)

## 📱 О проекте

**IT Project Manager** — это мобильное приложение для Android, предназначенное для управления IT-проектами, задачами и командой разработчиков. Приложение позволяет создавать проекты, ставить задачи, отслеживать статус выполнения на Kanban-доске, управлять участниками, оставлять комментарии и фиксировать затраченное время.

## 🛠 Стек технологий

| Компонент | Технология |
|-----------|------------|
| Язык программирования | Kotlin |
| Платформа | Android (min SDK 28) |
| Архитектура | MVVM |
| Управление состоянием | StateFlow |
| Асинхронность | Coroutines |
| База данных | Firebase Firestore |
| Аутентификация | Firebase Auth |
| Сборка | Gradle (Kotlin DSL) |

## 📱 Функциональные возможности

### Аутентификация
- Регистрация по email и паролю
- Вход в существующий аккаунт
- Выход из системы

### Управление проектами
- Создание проекта (ключ, название, описание)
- Просмотр списка проектов пользователя
- Редактирование проекта
- Архивирование проекта

### Управление задачами
- Создание задачи с выбором типа (Epic/Story/Task/Bug)
- Выбор приоритета (Low/Medium/High/Critical)
- Назначение исполнителя
- Оценка времени (estimate)
- Редактирование задачи
- Удаление задачи

### Kanban-доска
- 4 статуса: To Do, In Progress, In Review, Done
- Перемещение задач drag-and-drop
- История изменения статусов
- Фильтрация по исполнителю, приоритету, типу

### Комментарии
- Добавление комментариев к задачам
- Отображение автора и времени

### Учёт времени
- Добавление временных логов (часы + комментарий)
- Автоматический расчёт затраченного времени
- Прогресс-бар выполнения

### Ролевая модель
| Роль | Права |
|------|-------|
| Admin | Полный доступ ко всем проектам |
| Project Manager | Управление проектом и участниками, все задачи |
| Developer | Создание задач, изменение статуса своих задач, комментарии, учёт времени |
| Observer | Только просмотр |

## 🚀 Установка и запуск

### Требования
- Android Studio (последняя версия)
- Android SDK (min API 28)
- Аккаунт Firebase
